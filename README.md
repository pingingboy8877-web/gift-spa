# Gift Spa

A premium UK spa and gifting website reference build.

## Pages
Home · Treatments · Gifting · Wellness · About · Journal · Gallery · Media · Contact · FAQs · Privacy · Terms · Accessibility

## Stack
React + Vite + CSS. No environment variables or secret credentials are required.

## Run
npm install
npm run dev

## Production
npm run build

The project is intentionally front-end only so it is safe to publish as reusable source code. Replace placeholder business details, imagery, pricing and contact information before client delivery.
